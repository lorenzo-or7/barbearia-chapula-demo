# 💈 Barbearia Chapula

Site demonstrativo para a Barbearia Chapula, com serviços, preços, localização e agendamento rápido pelo WhatsApp.

🔗 **Acesse:** https://lorenzo-or7.github.io/barbearia-chapula-demo/

## 🛠️ Tecnologias
- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades
- Layout responsivo (celular, tablet e desktop)
- Lista de serviços e preços
- Botão de agendamento via WhatsApp
- Localização da barbearia
